# 远程管理

左上角「主机 / 端口转发 / 凭证」旁的网络图标打开「远程管理」。添加服务器，填写名称、最终 HTTPS 站点地址、账号和密码。服务器与账号保存在本机设置；登录密码可以保存到系统凭据管理器，Bearer 令牌仍只在内存中，密码和令牌都不写入设置或数据库。HTTP 仅允许本机联调地址，所有请求校验证书并拒绝重定向。

侧栏只显示已保存的服务器，顶部按名称、账号或地址搜索，右上角「+」添加服务器。单击选中；双击未登录的服务器尝试用已保存密码登录，没有密码时弹出登录框；双击已登录的服务器打开设备弹窗。服务器行显示未登录、已登录或已连接状态，已连接时附当前网络名称。退出登录不会删除服务器或保存的密码。

右键菜单提供「登录」「显示设备…」「连接网络…」「断开网络」「刷新」「退出登录」「编辑登录信息…」「删除」，按当前登录和网络状态启用。网络操作绑定所点击的服务器，切换侧栏选中项不会更换弹窗目标，也不会断开另一台服务器的网络。

登录框「保存密码到系统凭据管理器」默认开启。Windows 使用凭据管理器，macOS 使用 Keychain，Linux 使用 Secret Service；按服务器随机 UUID 保存，并校验服务器地址和账号以防改地址后误发旧密码。读取和保存都在后台进行；保存失败会明确提示，系统凭据服务不可用时不保存。登录失败不会自动删除旧密码，会重新打开隐藏密码的登录框供修改；取消勾选并成功登录后删除保存密码。便携版的数据目录不包含密码，移动到另一台电脑需要重新输入。

设备弹窗使用较宽、可滚动的列表，支持搜索设备名称、客户、虚拟 IP、设备编号和「仅当前网络设备」筛选，每页最多 20 项。显示 SSH 用户（默认 root），未连接所属网络的设备不能打开 SSH。弹窗内也可打开网络选择；网络弹窗按名称或网段搜索，显示网络设备数，支持连接和断开，切换前仍先停止旧网络。两种弹窗都实时显示当前网络、本机虚拟 IP 和本服务器的操作结果，Esc 关闭最上层弹窗。

新增服务器的地址默认为空，不预填测试站点；重新登录已保存的服务器时沿用自己的地址和账号。密码默认隐藏，可用眼睛按钮临时查看。「取消」与「登录」按钮等宽，也可按 Enter 提交、Esc 取消。

在服务器列表右键选择「删除」，确认后先停止该服务器的网络并退出登录，再清理系统密码及本机服务器记录；停止或密码清理失败时保留服务器记录供重试。删除不会修改服务器上的账号或设备，也不会停止其他服务器当前使用的网络。

设备列表使用新版 `GET /api/client/ssh/devices?limit=100&offset=...`，不再读取普通投屏目录 `/api/devices`。只显示服务器确认 SSH 已运行、租约有效且账号有权访问的在线设备，并读取 `networkId`、`expiresAt`；过期或禁用的设备不允许连接。在线租约不等于本机端口 22 一定可达。

虚拟 IP 是动态租约，设备或电脑租约到期后地址可以回收复用，不再长期绑定安装身份。连接前（包括 SSH 重连、复制标签及 SFTP 连接）在后台按硬件设备 ID 重新读取当前地址，不盲用旧标签中的 IP。SSH 主机密钥按服务器站点、客户网络和设备编号隔离保存；同一块板变更 IP 不丢失密钥身份，另一块板复用旧 IP 也不会沿用之前的信任，首次仍需确认密钥。

先点击对应客户的「连接当前网络」。已有本程序管理的网络时先停止旧网络，等待停止确认，再申请并启动新网络；不会同时连接两个客户网络。旧的受管 SSH 和 SFTP 通道在切换或断开时停止，重新连接旧标签前需先连接其所属网络。检测到另一程序正在占用组网入口或安装身份时不强杀它，给出冲突提示。

连接时按需触发 Windows UAC 授权，不要求整个 ShellLF 以管理员身份运行。取消授权会取消本次连接。普通登录和查看列表不需要提权。只有本机虚拟网卡和授权 IP 已出现后才显示已连接；这不等于设备 SSH 一定连通。选择 SSH 用户（默认 root），再点设备的「SSH 连接」；设备 SSH 密码、键盘认证和主机密钥确认仍走 ShellLF 原有流程，不使用网页登录密码。连接作为临时主机，不自动加入已保存的主机列表。

组件使用 EasyTier 2.6.4 官方 Windows x86_64 发行版。`ShellLF.exe` 旁需保留 `easytier-core.exe`、`easytier-cli.exe`、必需的 `wintun.dll` 和 `Packet.dll`，许可证在 `licenses/`。`Packet.dll` 使用 WinPcap 4.1.3 的 BSD 授权 x64 兼容库，满足官方核心的加载依赖，不分发原归档内的 Npcap 库，不安装 WinPcap 抓包驱动；实际虚拟网卡使用 Wintun。`scripts/bundle-easytier.ps1` 下载并校验固定归档及各文件 SHA-256，首次提取兼容库需要 7-Zip；启动前和提权后再次检查二进制哈希。应用内嵌网络管理脚本，运行目录由程序创建并设置私有 ACL；短期跨权限传递的令牌用当前用户 DPAPI 保护，包含网络密钥的 TOML 仅临时存在于该私有目录。

客户端身份为每份数据目录独立生成的 UUID，不复用开发板设备编号。授权校验安装身份、网络 ID、配置哈希、本机 IP、RPC 回环地址、租约和目标设备网段。启动前检查路由冲突，不更改默认路由和 DNS，不自动覆盖其他 VPN 路由。组网只启动本程序拥有的进程，退出时按进程句柄停止，Windows Job Object 保证工作进程异常退出时也关闭其 EasyTier 子进程；不按进程名结束其他软件。

后台按租约续期。账号或权限失效、网络停用、核心配置哈希或本机 IP 变化、租约到期时停止组网并提示重连；网络短暂故障不延长原租约。设备上线、离线或设备 IP 改变只更新设备目录，不再因列表变化重启组网；暂时没有在线设备时可保持已有网络并续租，首次连接仍要求在线设备。已连接网络每约 5 秒刷新一次在线目录，发现设备离线或地址变更时断开该设备的旧 SSH/SFTP，不影响同网络内其他设备；目录读取失败时暂停新的设备访问，但不擅自延长网络租约。显式断开、退出登录、关闭应用时停止本机组网，撤销租约并清理临时令牌和 TOML，防火墙仅创建和删除本程序本次运行专用的规则。应用崩溃时后台通过父进程 PID 和启动时间检测退出。

本功能只在 Windows x86_64 上提供组网，其他平台可查看登录列表但不能启动此组件。首次真实组网需要用有权限的服务器账号在 Windows 上验收：同客户多设备、跨客户切换、取消 UAC、账号撤权、租约失效及应用关闭。自动化测试注入假后端，不访问用户服务器、不创建真实网卡。

底层仍是 EasyTier 共享网络密钥。租约在正常客户端执行，并不等于服务器能强制驱逐保留旧密钥的恶意客户端；跨客户依赖独立网络，严格逐电脑即时撤权需要服务端数据面身份和密钥轮换支持。

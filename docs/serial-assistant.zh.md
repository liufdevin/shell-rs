# 串口助手

点击主窗口右上角的串口图标，打开「串口助手」独立标签页。入口默认显示，可在「设置 → 应用 → 串口助手」关闭。普通串口终端不再显示右侧「串口工具」，原有的 HEX 收发与退格设置可从终端标签菜单调整。

页面上方是接收区，下方是连接参数、命令组和发送框。选择串口和波特率后点「打开串口」；波特率可选常用值（包括 2000000），也可以选择「自定义波特率」后输入数值。可同时调整编码、数据位、校验和停止位。要更换参数，先关闭串口再修改；新接入的设备可通过刷新按钮查找。

助手直接打开本机串口，不必先新建主机。如果同一串口已由其他标签页或程序占用，需要先在原处断开。在发送框中，Enter 发送，Shift+Enter 插入换行；发送时仍按选中的 LF、CR 或 CRLF 添加行尾。

「编辑命令组」打开独立的「命令组」标签页：左边搜索和选择命令组，右边查看和编辑命令。也可在里面配置自动应答。「返回收发」保留编辑标签页，切换或关闭编辑页不影响串口连接。编辑中的内容与发送草稿分开，只有点「载入发送框」才替换发送草稿，且不会直接发送。

- **时间戳**：打开后为之后收到的行显示本机接收时间，已有行不补写。
- **过滤日志**：只显示匹配行，支持普通文本、正则和区分大小写。关闭过滤后恢复原日志。
- **保存日志**：将接收区保留的内容导出为 UTF-8 `.log`。有过滤时只保存匹配结果；开启时间戳时同时保存已记录的时间。关闭串口后也可以导出，重新打开串口会开始一份新日志。
- **自动滚动**：默认跟到最新输出。关闭时可停在正在看的位置，后台继续接收；再次打开跳到最新。

1. 点左侧「新建分组…」，在弹窗中输入组名并保存。可在左侧搜索或重命名分组。
2. 在右侧点「添加命令…」；选中一行后，也可用「插入命令…」将新命令放在该行之前。
3. 通过行内编辑按钮修改名称、延时和命令内容。HEX、行尾和 CRC 在命令弹窗中设置；命令表本身没有发送框。
4. 每条命令独立记住发送格式、换行、CRC 和等待时间。勾选「运行」决定是否参与整组发送；也可载入单条命令、复制、上移下移或删除，最近一次删除可以撤销。
5. 「运行整组」按保存顺序发送一次，不自动循环。每条本地串口写入完成后再等待指定时间，然后发送下一条；错误或超时停止。等待写入不等于设备已执行完成，响应匹配请使用自动应答。

「停止」不会撤回已经发出的数据。关闭助手、切换标签、重连或断开都会停止命令组；切换标签不会关闭串口。命令组与自动应答、定时发送互斥，避免同时发数据。定时发送仍有 60 次上限。

命令组按所选串口保存在本机数据库。如果该串口恰好对应一组旧版按主机保存的助手配置，会继续使用该配置。每个串口最多 32 个组，每组 128 条命令。名称最多 128 字节，单条内容最多 4 KiB，命令内容合计最多 256 KiB。命令不参与云同步，内容为明文，请勿保存密码、令牌等秘密。

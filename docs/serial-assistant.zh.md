# 串口助手

在已连接串口主机右侧打开「串口工具」，开启「增加串口助手」。此开关默认关闭，按主机保存；关闭时仍使用原来的收发、自动应答和连接页面。串口图标与实用工具不同，HEX 接收和 HEX 发送在底部同排显示。

开启时会立即切换到「串口助手」页，并回到页面顶部；即使之前停在「自动应答」或「连接」页，也能直接看到命令组。已开启助手的主机再次打开工具时，同样显示助手首页。

将串口终端拖到独立窗口后，窗口提供左侧终端、右侧串口工具的布局。右边缘的串口图标可收起或展开工具；助手开关和命令组仍按主机保存，HEX 控件只作用于该窗口中的终端。移回主窗口不会重开串口。

助手开启后，左侧终端显示接收内容，右侧管理命令和发送数据，不另开串口，也不复制一份无限增长的接收日志。

1. 输入命令组名称，点「新建组」。组名输入框也可用于重命名选中的组。
2. 在发送框输入内容，选择 HEX 发送、换行和 CRC；填入命令名称与发送后等待时间，点「添加到命令组」。
3. 点击已有命令名称，将其载入发送框编辑，再点「保存命令」；点「新命令」退出当前命令的编辑。
4. 每条命令独立记住发送格式、换行、CRC 和等待时间。勾选「运行」决定是否参与整组发送；也可单条发送、上移、删除，最近一次删除可以撤销。
5. 「运行整组」按保存顺序发送一次，不自动循环。每条本地串口写入完成后再等待指定时间，然后发送下一条；错误或超时停止。等待写入不等于设备已执行完成，响应匹配请使用自动应答。

「停止」不会撤回已经发出的数据。关闭助手、关闭工具、切换标签、重连或断开都会停止命令组。命令组与自动应答、定时发送互斥，避免同时发数据。定时发送仍有 60 次上限。

本轮命令组的确认发送针对本地串口；不支持确认发送的远程传输会明确报错并停止，不会静默认为已发送。原有远程串口的普通发送不变。

每台主机最多 32 个组，每组 128 条命令，界面每页最多显示 6 条。名称最多 128 字节，单条内容最多 4 KiB，命令内容合计最多 256 KiB。命令保存在本机数据库，不参与云同步；删除保存的主机会一并删除其助手设置和命令组。命令内容为明文，请勿保存密码、令牌等秘密。
